Рабочая папка - папка со всеми файлами проекта
Индекс добавляет изменения перед сохранениями
Коммит — это сохранение изменений в истории Git с сообщением, в котором объясняется, что изменилось

Git — это система контроля версий, которая работает локально на компьютере.
GitHub — это веб-платформа для хранения репозиториев Git в интернете и совместной работы.

Использованные команды:
git status — показывает состояние файлов (изменения в них; в индексе файл или нет)
git diff — сравнивает рабочую папку с индексом (что изменено, но не добавлено).
git diff --staged — сравнивает индекс с последним коммитом

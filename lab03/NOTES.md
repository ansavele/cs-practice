Раздел 2. Сравнение версий и поиск изменений

git diff — показывает разницу между двумя состояниями файлов.
git show — показывает содержимое одного конкретного коммита.
git log — показывает список всех коммитов в истории.
Команда git log -S ищет коммиты, где добавлялось или удалялось слово 'def'.
Команда git blame показывает, кто и когда последний раз менял каждую строку.

Раздел 3. Восстановление файла
git restore lab03/calc.py — возвращает файл к состоянию последнего коммита, отменяя все незакоммиченные изменения.
git restore --source=HEAD~2 lab03/calc.py — берет версию файла из конкретного коммита (двумя шагами назад) и кладет её в рабочую папку.
Если бы я не выполнил повторный git restore после --source, то мои текущие правки (функции вычитания и умножения) были бы затёрты старой версией файла.

Раздел 4. Ошибочный коммит и отмена
git revert создает новый коммит, который отменяет изменения указанного коммита, сохраняя при этом всю историю.
git reset --hard удаляет коммиты и изменения навсегда, переписывая историю.
В опубликованной истории безопаснее revert, потому что он не удаляет коммиты, а добавляет новый, отменяющий. reset --hard сломал бы работу коллегам, у которых уже есть старая версия истории.
